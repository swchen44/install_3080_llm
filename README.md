# RTX 3080 LLM 與 AI 研究交接

本專案記錄 RTX 3080 20GB、128GB RAM 的本機模型部署、效能測量，以及其他 AI 主題研究。從 [研究索引](docs/research/README.md) 開始，詳細執行過程見 [執行日誌](docs/research/execution.md)，原始量測資料位於 `results/` 和 `docs/research/logs/`。

[原始實驗計畫](RTX3080_20GB_Strata_Qwen_Codex_PLAN_v2.md) 和 `scripts/`、`tests/` 提供實驗流程。部分文件含本機路徑、歷史設定或尚待實測的建議；應以日誌中的實際結果為準。

模型權重、本機環境、生成影片與圖片產出不包含在此 repository。部分研究 HTML 原本引用的生成圖片因此不隨庫發布；研究文字與數值結果仍保留。
